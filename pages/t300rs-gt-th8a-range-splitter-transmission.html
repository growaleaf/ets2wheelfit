Thrustmaster T300RS GT Edition + TH8A Add-On Shifter + Range-Splitter Transmission (Scania-style)

Whether this wheel + H-shifter combo's physical positions cover ETS2/ATS's Range-Splitter Transmission (Scania-style) gearbox mode, and whether its bundled pedals give you a clutch axis.

Shifter has: 7 forward gears + reverse (8 physical H-pattern positions)
Mode needs: Needs a shifter with at least 7 physical positions, plus 2 free button(s) bound to Shifter Toggle 1 and 2. Both toggles used together — the real Scania H-shifter layout. 'Shifter Toggle: 1' switches ranges, 'Shifter Toggle: 2' switches splits.

This shifter's 8 physical positions cover the 7 this mode needs.

Shifter Toggle buttons are bound to any free button in-game — this build does not score free button count because the manufacturer pages for these wheels do not all publish an exact button total; every combo below has multiple spare buttons or paddles.

Clutch axis: Not stated by the manufacturer's own page

The T300RS GT Edition's own product page names its bundled pedal set "T3PA-GT" but does not state its pedal count or whether a clutch pedal is included — its own configurator sells a separate 3-pedal clutch-equipped set (T3PA Add-On) as an upgrade, which is suggestive but not a direct statement about the bundled set. Reported as not stated rather than guessed.

This shifter also has a built-in sequential (+/-) mode, not used by ETS2/ATS — the game has no sequential transmission type.

Shifter sources: Thrustmaster — TH8A Add-On Shifter product page, fetched 2026-10-15: "7+1" gears (7 forward gears plus reverse); "Sequential (+/-) modes"; compatible wheelbases include "T300 RS". · Thrustmaster — T300RS GT Edition product page, fetched 2026-10-15: lists bundled "T3PA-GT PEDALS" (pedal count not stated on this page) and separately sells "T3PM", "T3PA Add-On" (3-pedal, clutch-equipped per thrustmaster.com's own T3PA Add-On page) as optional pedal-set upgrades.
Mode source: SCS Software — ETS2/ATS input config reference page: "This configuration tries to emulate a layout of a real Scania H-shifter" — "the 'Shifter Toggle: 1' switches between gear ranges and 'Shifter Toggle: 2' switches between splitted gears."

What this counts

"Physical H-pattern positions" are the forward gear gates plus reverse, counted from the shifter manufacturer's own product page. "Gearbox mode" requirements are read directly from SCS Software's own ETS2/ATS input configuration reference page. "Clutch axis" reports whether the wheel's own bundled pedal set includes a clutch pedal, read from that wheel's own product page.

This tool reports counts and manufacturer statements. It does not tell you a combo is required, sufficient, or the best choice for ETS2 or ATS — that judgment is yours.
